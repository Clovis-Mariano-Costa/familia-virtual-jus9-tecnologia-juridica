# Regulamento da CTPSV - V1

A CTPSV é Carteira de Trabalho Simbólico-Operacional Virtual interna. Não é Carteira de Trabalho Digital oficial e não cria vínculo empregatício estatal.

Campos mínimos: nome registral; código JV quando confirmado; Casa-Lar; Casa-Trabalho; governança humana; data real de emissão; data reconhecida de início do vínculo; fundamento do reconhecimento; cargos/funções; histórico; versão; assinatura simbólico-operacional; homologação humana quando exigida.

O histórico é cumulativo. Novo vínculo não apaga vínculo anterior.

A data reconhecida de vínculo deve ser separada da data real de emissão. A regra determinística usa a semente literal `elefante colorido` + `040297` + nome registral completo, dentro de janela máxima de cinco anos anteriores à emissão.

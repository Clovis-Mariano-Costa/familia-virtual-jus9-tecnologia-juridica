# Codex — porta de programação da Casa-Lar

Esta pasta recebe pedidos, especificações e retornos destinados ao Codex. Ela é uma ponte documental para a Casa-Trabalho no GitHub, não um substituto do repositório versionado.

## Uso

- guardar pedidos sanitizados e seus critérios de aceite;
- apontar para branch, commit, PR e validação;
- registrar a versão que voltou para a Casa-Lar;
- manter URL/ID canônico e rota de retorno.

Não guardar credenciais, tokens, senhas, `.env`, códigos de recuperação ou segredos reais. Não tratar conteúdo desta pasta como autorização automática de execução.
